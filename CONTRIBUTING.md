# Contributing to Fetchly

Thanks for helping!

- **Bugs:** open an issue with your operating system and version, what you did, what you expected, and the contents of `error.log` if it exists (`%APPDATA%\Fetchly` on Windows, `~/.config/Fetchly` on Linux).
- **Pull requests:** keep them focused on one change, and run `python -m tests.test_engine` before submitting.
- **Style:** Python 3.10+, standard library first, 120-character lines.
