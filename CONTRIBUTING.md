# Contributing to Fetchly

Thanks for helping!

- **Bugs:** open an issue with your Windows version, what you did, what you expected, and the contents of `%APPDATA%\Fetchly\error.log` if it exists.
- **Pull requests:** keep them focused on one change, and run `python -m tests.test_engine` before submitting.
- **Style:** Python 3.10+, standard library first, 120-character lines.
