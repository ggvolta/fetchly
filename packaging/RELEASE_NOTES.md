The first release of Fetchly.

**Download**
- **Fetchly-Setup-1.0.0.exe** installs Fetchly with Start menu and desktop shortcuts (64-bit Windows 10 or 11).
- **Fetchly-1.0.0-portable.zip** runs without installing: unzip it and open `Fetchly.exe`.
- **Fetchly-Extension-1.0.0.zip** is the browser extension, also included in the installer at `C:\Program Files\Fetchly\extension`.

The installer isn't code-signed yet, so Windows SmartScreen may warn you the first time. Choose **More info**, then **Run anyway**.

**In this version**
- Up to 32 connections per file with dynamic splitting, so every connection stays busy until the end
- Resume after pauses, lost connections, crashes and restarts
- Browser integration for Chrome, Edge, Brave, Opera and Vivaldi, including a button for downloading videos
- Categories, a download queue with a scheduler, speed limiter, batch downloads and light and dark themes
